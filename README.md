# Hop Emperor

## Goals:
#### Recreate Jump King
We wanted to recreate Jump King by Nexile, a "Foddian rage game" platformer. 
#### Develop The Collision System Ourselves
One of the biggest reason we wanted to recreate Jump King and believed it would be a challenge that would help us learn is because we wanted to fully develop a 2d collision system ourselves.
